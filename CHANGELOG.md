# Changelog

## 1.1.0
- Smoother recording: frames are piped to ffmpeg and converted to a GIF afterwards, so the game stalls far less.
- Better quality: per-clip colour palette and real-time playback speed. Default width is now 1280 px.
- Choose the encoding device (NVIDIA GPU or CPU) in settings. Requires ffmpeg on PATH, or set its path in the config file.
- Optional recording indicator with a position setting.

## 1.0.0
- Record a short GIF screenshot with a dedicated keybind.
- Configure recording length, FPS and width in Mod Menu.
